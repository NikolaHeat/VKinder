
# VKinder

VKinder — бот для сообщества ВКонтакте, который помогает
находить подходящие анкеты пользователей VK.

Бот ищет открытые профили по возрасту, полу и городу,
показывает фотографии и позволяет сохранять понравившиеся
анкеты в избранное.

## Возможности

- Поиск пользователей ВКонтакте.
- Подбор анкет по возрасту, полу и городу.
- Отображение имени, фамилии и ссылки на профиль.
- Показ трёх самых популярных фотографий профиля.
- Переход к следующей анкете.
- Добавление анкеты в избранное.
- Просмотр сохранённых анкет.
- Хранение пользователей, анкет и избранного в PostgreSQL.
- Обработка ошибок при обращении к VK API.

## Используемые технологии

- Python 3
- VK API

- PostgreSQL
- psycopg2-binary

## Установка проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/NikolaHeat/VKinder.git
cd VKinder
```

### 2. Создание виртуального окружения

```bash
python -m venv .venv
```

Активация в Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

В файле `requirements.txt` используются:

```text
vk-api
psycopg2-binary
python-dotenv
```

## Настройка проекта

### 1. Создание базы данных

Установите PostgreSQL и создайте базу данных:

```sql
CREATE DATABASE vkinder;
```

### 2. Создание файла .env

В корневой папке проекта создайте файл `.env`.

Пример содержимого:

```env
VK_TOKEN=your_community_token
USER_TOKEN=your_user_token

DB_NAME=vkinder
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5433
```

Замените значения на свои.

`VK_TOKEN` — токен сообщества ВКонтакте.

`USER_TOKEN` — пользовательский токен VK API.

`DB_NAME` — название базы данных.

`DB_USER` — пользователь PostgreSQL.

`DB_PASSWORD` — пароль PostgreSQL.

`DB_HOST` — адрес сервера PostgreSQL.

`DB_PORT` — порт PostgreSQL. Обычно используется 5432,
но в вашей конфигурации может быть другой порт.

Файл `.env` содержит секретные данные и не должен
загружаться в GitHub.

### 3. Создание таблиц

Выполните:

```bash
python create_db.py
```

Программа создаст три таблицы:

- `users`
- `candidates`
- `favorites`

## Запуск бота

Выполните:

```bash
python main.py
```

При успешном запуске появится сообщение:

```text
VKinder запущен!
```

После этого откройте сообщения сообщества ВКонтакте,
для которого настроен бот.

## Команды бота

| Команда | Назначение |
|---|---|
| `начать` | Показать список команд |
| `привет` | Показать список команд |
| `start` | Показать список команд |
| `поиск` | Найти подходящие анкеты |
| `следующая` | Показать следующую анкету |
| `в избранное` | Сохранить текущую анкету |
| `избранное` | Показать сохранённые анкеты |

Если в профиле пользователя отсутствует полная дата
рождения, бот предложит указать возраст вручную.

## База данных

Для хранения данных используется PostgreSQL.

Подключение выполняется с помощью библиотеки
`psycopg2`, которая устанавливается из пакета
`psycopg2-binary`.

### Таблица users

Хранит пользователей, которые взаимодействуют с ботом.

Поля:

- `id` — первичный ключ.
- `vk_id` — уникальный идентификатор пользователя VK.
- `first_name` — имя.
- `last_name` — фамилия.

### Таблица candidates

Хранит найденные ботом анкеты пользователей ВКонтакте.

Поля:

- `id` — первичный ключ.
- `vk_id` — уникальный идентификатор анкеты VK.
- `first_name` — имя.
- `last_name` — фамилия.
- `profile_url` — ссылка на профиль ВКонтакте.

### Таблица favorites

Хранит анкеты, добавленные пользователями в избранное.

Поля:

- `id` — первичный ключ.
- `user_id` — внешний ключ на таблицу `users`.
- `candidate_id` — внешний ключ на таблицу `candidates`.

Пара `user_id` и `candidate_id` является уникальной.
Поэтому одна и та же анкета не добавляется повторно
в избранное одного пользователя.

## Схема базы данных

Связи между таблицами:

```text
users (1) ───── (N) favorites (N) ───── (1) candidates
```

Один пользователь может сохранить много анкет.

Одна анкета может быть сохранена несколькими пользователями.

Внешние ключи:

- `favorites.user_id` → `users.id`
- `favorites.candidate_id` → `candidates.id`

Для обоих внешних ключей используется
`ON DELETE CASCADE`.

Это означает, что при удалении пользователя
или анкеты связанные записи в таблице `favorites`
удаляются автоматически.

## Структура проекта

```text
VKinder/
│
├── main.py
├── vk_api_client.py
├── database.py
├── create_db.py
├── config.py
├── requirements.txt
├── README.md
├── .gitignore
└── .env
```

Назначение файлов:

- `main.py` — основная логика бота и обработка сообщений.
- `vk_api_client.py` — работа с VK API, поиск пользователей
  и получение фотографий.
- `database.py` — подключение к PostgreSQL и операции с БД.
- `create_db.py` — создание таблиц базы данных.
- `config.py` — загрузка настроек проекта.
- `requirements.txt` — зависимости проекта.
- `README.md` — документация.
- `.env` — секретные настройки и токены.
- `.gitignore` — исключения для Git.

## Безопасность

Токены ВКонтакте и пароль PostgreSQL хранятся
в локальном файле `.env`.

Файл `.env` должен быть указан в `.gitignore`.

Настоящие токены и пароли нельзя публиковать
в репозитории или документации.
