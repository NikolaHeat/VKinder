# VKinder

VKinder — бот для сообщества ВКонтакте, который помогает искать подходящие анкеты пользователей VK для знакомств.

## Возможности

Бот умеет:

- получать информацию о пользователе;
- искать подходящие анкеты по возрасту, полу и городу;
- показывать имя и ссылку на профиль;
- показывать 3 самые популярные фотографии профиля;
- переключаться на следующую анкету;
- добавлять анкеты в избранное;
- показывать список избранных анкет;
- сохранять данные в PostgreSQL.

## Используемые технологии

- Python
- VK API
- PostgreSQL
- psycopg2
- vk-api
- python-dotenv

## Установка

1. Клонировать репозиторий:

```bash
git clone <ссылка-на-репозиторий>
```

2. Перейти в папку проекта:

```bash
cd VKinder
```

3. Создать виртуальное окружение:

```bash
python -m venv .venv
```

4. Активировать виртуальное окружение.

Для Windows:

```bash
.venv\Scripts\activate
```

5. Установить зависимости:

```bash
pip install -r requirements.txt
```

## Настройка

В корне проекта необходимо создать файл `.env`.

Пример содержимого:

```env
DB_NAME=vkinder
DB_USER=postgres
DB_PASSWORD=your_password
DB_HOST=localhost
DB_PORT=5433

VK_TOKEN=your_group_token
USER_TOKEN=your_user_token
```

Где:

- `DB_NAME` — название базы данных PostgreSQL;
- `DB_USER` — пользователь PostgreSQL;
- `DB_PASSWORD` — пароль PostgreSQL;
- `DB_HOST` — адрес сервера PostgreSQL;
- `DB_PORT` — порт PostgreSQL;
- `VK_TOKEN` — токен сообщества ВКонтакте;
- `USER_TOKEN` — пользовательский токен ВКонтакте.

## Создание базы данных

Перед первым запуском необходимо создать базу данных PostgreSQL с названием `vkinder`.

После этого выполнить:

```bash
python create_db.py
```

Скрипт создаст необходимые таблицы.

## Запуск бота

Для запуска выполнить:

```bash
python main.py
```

После успешного запуска в терминале появится сообщение:

```text
VKinder запущен!
```

## Команды бота

В чате сообщества доступны следующие команды:

- `начать` — показать список доступных команд;
- `поиск` — найти подходящие анкеты;
- `следующая` — показать следующую анкету;
- `в избранное` — сохранить текущую анкету;
- `избранное` — показать сохранённые анкеты.

Если в профиле пользователя не указана полная дата рождения,
бот предложит указать возраст вручную.

## База данных

В проекте используются три таблицы:

### users

Хранит информацию о пользователях бота.

### candidates

Хранит найденные ботом анкеты пользователей ВКонтакте.

### favorites

Хранит информацию об анкетах, добавленных пользователями в избранное.

## Схема базы данных

Связи между таблицами:

```text
users
  |
  | 1
  |
  | N
favorites
  | N
  |
  | 1
  |
candidates
```

Таблица `favorites` связывает пользователя бота с выбранной им анкетой.

Логическая структура:

```text
users
-----
id
vk_id
first_name
last_name

candidates
----------
id
vk_id
first_name
last_name
profile_url

favorites
---------
id
user_id
candidate_id
```

Связи:

- `favorites.user_id` → `users.id`;
- `favorites.candidate_id` → `candidates.id`.

## Структура проекта

```text
VKinder/
│
├── main.py
├── vk_api_client.py
├── database.py
├── create_db.py
├── config.py
├── requirements.txt
├── README.md
├── .gitignore
└── .env
```

Назначение файлов:

- `main.py` — основная логика бота и обработка сообщений;
- `vk_api_client.py` — работа с VK API, поиск пользователей и фотографий;
- `database.py` — работа с PostgreSQL;
- `create_db.py` — создание таблиц базы данных;
- `config.py` — загрузка настроек проекта;
- `requirements.txt` — зависимости проекта;
- `.env` — секретные настройки и токены;
- `.gitignore` — список файлов, которые не должны попадать в Git.

## Безопасность

Токены VK и данные для подключения к PostgreSQL хранятся в файле `.env`.

Файл `.env` добавлен в `.gitignore` и не должен загружаться в GitHub.

Настоящие токены и пароль базы данных нельзя указывать в `README.md` или других файлах репозитория.
